## 🧭 Cómo usar estos repositorios

Cada laboratorio, ayudantía y proyecto vive en su propio repositorio. Todos siguen la misma estructura de README:

| Sección | Qué encontrarás |
| :--- | :--- |
| 🎥 **Video** | El video que debes ver **antes** de la sesión |
| 📂 **Material** | Guías, código VHDL/C, constraints y el proyecto de Vivado listo para abrir |
| 📚 **Preparación para el Quiz** | Lo que se evalúa en los primeros minutos del laboratorio |
| 🧪 **Actividad práctica** | Lo que se desarrolla durante la sesión |

> [!IMPORTANT]
> El material vigente del semestre está en la rama **`2026-2`**, que es la que verás por defecto al entrar a cualquier repositorio. La rama `main` se conserva como archivo histórico del semestre anterior — no la uses para estudiar.
